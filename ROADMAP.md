# Postmark roadmap

**Status: Work in Progress**

## Implemented in development
- Gmail sync and separate account contexts
- Multilingual local email organization
- Account-authorized multi-model inference with a local Ollama route
- Autonomous creation and publishing of local categories with rollback
- Queue recovery, retries and rate-limit awareness
- Cleanup review and bounded bulk operations
- Token and background-activity reporting

## In progress
- Human-verified accuracy on multilingual subtypes and workflows
- Lowering tokens consumed per useful result
- Improving local memory usage and message-processing throughput
- Reliability validation during unattended long-running operation
- Streamlining navigation, screen density and responsive layouts
- Sanitized screenshots and public demo content

## Not yet released
- Public installation package
- Verified production-safe multi-user deployment
- Repeatable installation packaging beyond the reviewed source checkout

Roadmap items indicate active engineering goals, not guaranteed shipped functionality.
